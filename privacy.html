Política de Privacidade

Última atualização: 5 de julho de 2026

Esta Política de Privacidade está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

Coleta de dados

O Sound System Go pode coletar os seguintes dados:

  • Nome e e-mail (no caso de login com Google)
  • Nome de usuário e e-mail de contato (no caso de contas de coletivo)
  • Dados de localização (quando autorizado pelo usuário)

Uso dos dados

Os dados coletados são utilizados para:

  • Permitir o funcionamento da plataforma
  • Personalizar a experiência do usuário com base na localização
  • Gerenciar contas de usuário e coletivos

Localização

O uso de GPS é opcional e depende da autorização do usuário.

A localização é utilizada apenas para exibir eventos próximos.

Compartilhamento de dados

O Sound System Go não vende ou compartilha dados pessoais com terceiros, exceto quando necessário para o funcionamento da plataforma.

Segurança

São adotadas medidas razoáveis para proteger os dados dos usuários, porém não é possível garantir segurança absoluta.

Direitos do usuário

O usuário pode solicitar a exclusão de sua conta ou dados a qualquer momento entrando em contato pelo Instagram @soundsystemgo.

Alterações

Esta política pode ser atualizada a qualquer momento, sendo recomendada a revisão periódica.
